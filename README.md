# saeidch.github.io

Personal academic homepage of Saeid Chahardoli, live at <https://saeidch.github.io>.

Built with the [Academic Pages](https://github.com/academicpages/academicpages.github.io) Jekyll template and hosted on GitHub Pages.

## Editing

- Homepage content (all sections): `_pages/about.md`
- Header menu: `_data/navigation.yml`
- Sidebar name, bio and links: `author:` block in `_config.yml`
- Profile photo: `images/profile.png` (or set `author.avatar` to a new file in `images/`)
- CV and other downloads: put them in `files/`, e.g. `files/CV.pdf` → `/files/CV.pdf`

Every push to `master` rebuilds the site in a minute or two.
